# 🌏 Best-Practice Restoration Methodology — Broad-Scale Temperate/Riverine Properties

> [!abstract] Purpose
> A working knowledge base for **ecological restoration on broad-scale Australian temperate/riverine landholdings** (Murray–Darling Basin, riparian corridors, floodplain and wetland country). It pulls together the **latest ecology-monitoring methods** and **pest-suppression techniques** into a single **plan → monitor → act → review** adaptive-management framework.
>
> Scope set with the landholder: **temperate/riverine biome**, focus on **vertebrate pests + invasive weeds**, output formatted for **Obsidian**.

## 🔑 Ten cross-cutting principles (the short version)

1. **Anchor everything to a reference ecosystem.** Define the local native target state (PCT/EVC/Regional Ecosystem) and measure recovery as a proportion of it. → [[Restoration Planning & Standards (SERA)]]
2. **Set a baseline before you touch anything.** You cannot show recovery without a measured starting point. → [[Adaptive Management Framework]]
3. **Make goals SMART and write them down.** "Evaluation can only be as rigorous as the monitoring that informs it." → [[Adaptive Management Framework]]
4. **Monitor on a fixed cadence with pre-agreed triggers.** Tiered trigger points beat a single red-light threshold. → [[Monitoring Schedules & Triggers]]
5. **Coordinate at landscape scale.** Neighbour-inclusive, whole-of-property and cross-tenure effort beats isolated patches — true for both pests and weeds. → [[Vertebrate Pest Control]]
6. **Integrate methods.** No single tool works alone — bait + shoot + trap + habitat manipulation for pests; chemical + mechanical + biocontrol + revegetation for weeds.
7. **Sequence weed work top-of-catchment downstream, least-to-most infested.** Stops reinvasion from upstream. → [[Invasive Weed Management]]
8. **Follow-up is non-negotiable.** Regrowth and reinvasion will undo a one-off effort; budget for multiple seasons.
9. **Restore competitive native cover.** The best defence against weed reinvasion is a dense native community. → [[Invasive Weed Management]]
10. **Use open data standards.** Darwin Core / Atlas of Living Australia / BioNet so your data is interoperable and durable. → [[Remote Sensing & Data Standards]]
