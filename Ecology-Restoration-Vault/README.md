# Ecology Restoration Vault

An **Obsidian-flavoured** knowledge base compiling best-practice **ecology monitoring methods** and **pest-suppression techniques** into an adaptive-management restoration methodology for **broad-scale Australian temperate/riverine properties** (Murray–Darling Basin / riparian / floodplain / wetland).

## How to use it in Obsidian

1. Copy the entire `Ecology-Restoration-Vault/` folder into your Obsidian vault (or open this folder *as* a vault: Obsidian → "Open folder as vault").
2. Open **`00 - Restoration Methodology MOC.md`** — that's the home/Map-of-Content note. Everything links out from there.
3. Switch on the **Graph view** to see how the notes connect, and use **`[[wikilinks]]`** to navigate.

## Structure

| Folder | Contents |
|---|---|
| `00 - Restoration Methodology MOC.md` | Home note / Map of Content — start here |
| `Framework/` | The adaptive-management cycle, SERA standards, monitoring schedules & triggers, regulation/incentives |
| `Monitoring/` | Vegetation condition, riparian/wetland condition, fauna methods, remote sensing & data standards |
| `Pest Suppression/` | Vertebrate pest control, invasive weed management |
| `Field SOP/` | A condensed, field-ready annual protocol |
| `_meta/` | Master source & reference list |

## Conventions

- Every note has **YAML frontmatter** (title, aliases, tags, dates) and **`#tags`** for filtering.
- Claims are **cited inline** with source name + URL; the master list lives in `_meta/Sources & References.md`.
- **Callouts** (`> [!warning]`, `> [!tip]`, `> [!note]`) flag compliance issues, practical tips and caveats.

## ⚠️ Important

This is a **research compilation, not legal/agronomic advice**. Pesticide use (**1080, PAPP, herbicides near water**) is regulated and **state-variable**, and permits are time-limited. **Verify current APVMA permits, product labels, and state codes of practice before acting.** Where the research could only confirm a figure from a search snippet (not the primary PDF), the note says so — double-check those against the cited source.
