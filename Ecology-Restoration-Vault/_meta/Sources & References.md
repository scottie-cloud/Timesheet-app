# 📚 Sources & References

Master list of sources cited across the vault, grouped by theme. Compiled **2026-06-10**. Australian guidance strongly preferred; currency notes included.

> [!warning] Verification caveats
> Several primary government PDFs blocked automated fetching during research, so some figures rest on **search-engine extracts** of those same authoritative pages rather than full-text reads. Where a specific number matters (plot dimensions, scoring totals, target percentages, permit expiries), **verify against the linked source** before relying on it. Key corrections already applied: the SERA recovery wheel is **five-star** (not six); several foundational manuals **predate 2018** but remain the cited standard.
