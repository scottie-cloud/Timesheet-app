# 🧰 Field SOP — Annual Restoration Cycle

> [!abstract] Purpose
> The condensed, field-ready version of the methodology — what to do each **season**, distilled from the [[Adaptive Management Framework]]. Tune to your property, seasons and conditions. **This is a guide, not a substitute for current permits, labels and codes of practice.**

> [!danger] Before any pesticide work
> Confirm **current** 1080/PAPP licensing & setbacks ([[Vertebrate Pest Control]]) and **aquatic-registered** herbicide permits ([[Invasive Weed Management]]). See [[Regulation, Incentives & Markets]].

---

## 🥇 Year 0 — Establish before you act

- [ ] Define the **[[Restoration Planning & Standards (SERA)|reference ecosystem]]** for each land type (PCT/EVC/RE).
- [ ] Write **SMART goals** per asset/reach → [[Adaptive Management Framework]].
- [ ] **Baseline survey:** condition plots ([[Vegetation & Habitat Condition Monitoring]]), riparian RARC ([[Riparian & Wetland Condition Tools]]), fauna ([[Fauna Monitoring Techniques]]), pest activity index, weed map.
- [ ] Install **fixed photo-points** and mark plot/transect locations (GPS).
- [ ] Capture a **satellite NDVI baseline** + optional drone survey → [[Remote Sensing & Data Standards]].
- [ ] Set **decision triggers** (🟢🟡🔴) per indicator → [[Monitoring Schedules & Triggers]].
- [ ] **Whole-farm plan:** prioritise sites, corridors, paddock-tree protection.
- [ ] Talk to **neighbours** — coordinate pest/weed timing across boundaries.

## 🗓️ Seasonal calendar (temperate / riverine)

> [!note] Southern-hemisphere seasons; adjust to local conditions and any environmental-watering events.

### ☀️ Summer (Dec–Feb)
- [ ] **Blackberry** foliar spray timing approaches (late-summer/autumn before dormancy) — scout extent.
- [ ] **Frog** breeding-season acoustic/FrogID surveys; **eDNA** sampling of waterholes.
- [ ] **Bird** surveys (2 ha / 20-min) — repeat seasonal round.
- [ ] **Salvinia/water hyacinth/cumbungi** at peak growth — monitor, treat warm-season aquatic weeds.
- [ ] **Feral pig** aerial/thermal control where animals concentrate on water in dry conditions.
- [ ] Watch heat stress on any **Elliott/pitfall** trapping (shade, insulation).

### 🍂 Autumn (Mar–May)
- [ ] **Fox baiting round #1** (autumn — juvenile dispersal) — coordinated, twice-yearly. 
- [ ] **Blackberry / woody weeds** foliar spraying (key window).
- [ ] **Willow** control (cut-stump/stem injection) as growth slows — staged to protect banks.
- [ ] **Rabbit:** warren ripping (dry ground), follow with baiting/fumigation.
- [ ] **Condition plots** re-measure (if annual/biennial due) — consistent timing matters.

### ❄️ Winter (Jun–Aug)
- [ ] **Fox den** reconnaissance; plan CO fumigation for late winter/spring (cubs >4 wks).
- [ ] **Sagittaria** in drawn-down/dewatered irrigation channels (imazapyr) — winter window.
- [ ] **Deer:** thermal-assisted aerial/ground control (good detection in open, cold conditions).
- [ ] **Planning & review:** analyse last year's data, update triggers, apply for [[Regulation, Incentives & Markets|grants/permits]].
- [ ] Order/grow **revegetation** stock (local provenance) for spring planting.

### 🌱 Spring (Sep–Nov)
- [ ] **Fox baiting round #2** (late winter/spring — breeding) + **den fumigation** window.
- [ ] **Revegetation planting** into treated/weeded sites; protect with guards/fencing.
- [ ] **Willow** seed-set prevention (flowering spring) — finish control before seed ripens.
- [ ] **Waterbird/breeding** surveys; **eDNA** around any environmental watering.
- [ ] **Camera-trap** standardised array (annual occupancy round).
- [ ] **Drone** structural/cover survey before summer.

## 🔁 Every control program (pests & weeds)
- [ ] **Bracket it** — measure activity/extent **before and after** to quantify knockdown. → [[Monitoring Schedules & Triggers]]
- [ ] **Integrate methods** (don't rely on one tool).
- [ ] **Follow-up** the same season for regrowth/survivors — budget for it.
- [ ] **Log to Darwin Core / ALA / FeralScan / FrogID** → [[Remote Sensing & Data Standards]].

---

## 📋 Annual review (close the loop)
- [ ] Score the **[[Restoration Planning & Standards (SERA)|five-star Recovery Wheel]]** for each site.
- [ ] Compare indicators to **trigger thresholds**; note any 🟡/🔴.
- [ ] **Adjust the plan** — change methods/inputs where targets aren't tracking.
- [ ] Update photo-point series and the **whole-farm map**.
- [ ] Report for any **[[Regulation, Incentives & Markets|funding/market]]** obligations.
